# algoritm

Repositório demonstrativo de como funcionam os algoritmos mais comuns no mundo da programação.

- Execução passo a passo, com explicação no terminal
- Demonstração da complexidade em Big-O
- Feito em C# / .NET (funciona em qualquer versão do .NET Core)

## Como executar

```bash
dotnet run          # abre o menu interativo
dotnet run -- 1     # executa direto a opção 1
dotnet run -- busca # executa pelo nome
```
